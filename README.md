# Лабораторна робота №5

**Варіант 2. Задача про шахового коня** 

## 📝 Опис завдання
Дано шахівницю, необхідно знайти найкоротшу відстань (мінімальна кількість ходів), яку повинен пройти кінь, щоб досягти заданого пункту призначення із заданого джерела.
Кінь може ходити у восьми можливих напрямках від даної клітини (згідно зі стандартними правилами шахів).

## 📥 Вхідні дані
Вхідні дані зчитуються з файлу `input.txt`.
Файл містить:
1. Розмір поля `N` (дошка N x N).
2. Координати стартової точки `(x, y)`.
3. Координати точки призначення `(x, y)`.

*Приклад `input.txt`:*
15
7, 0
0, 7

## 📤 Вихідні дані
Результуючий файл `output.txt` містить ціле число — значення найкоротшого шляху (кількість ходів) від початкової точки до точки призначення.

*Приклад `output.txt`:*
6

# Лабораторна робота №9

**Рівень 2. Варіант 2. Пошук підрядка за алгоритмом Боєра-Мура**

## 📝 Опис завдання
Створити функцію мовою програмування Python, яка приймає дві стрічки: 
* `haystack` (довільний текст)
* `needle` (шукана стрічка)

Програма повинна знайти індекси всіх входжень стрічки `needle` у стрічці `haystack` та повернути список цих індексів, використовуючи метод Боєра-Мура для оптимізованого пошуку підстрічки.

## 📥 Вхідні дані
Функція `boyer_moore_search(haystack, needle)` приймає два рядки.
*Приклад:* `haystack = "abracadabra"`, `needle = "abra"`

## 📤 Вихідні дані
Функція повертає масив (список) цілих чисел — початкових індексів усіх знайдених входжень. Якщо підрядок не знайдено, повертається порожній масив.
*Приклад результату:* `[0, 7]`

## 📂 Структура проєкту
* `boyer_moore.py` — основний скрипт, що містить реалізацію алгоритму Боєра-Мура. Використовується евристика (правило) "поганого символу" для зміщення шаблону, що дозволяє значно прискорити пошук порівняно з наївним методом.
* `test_boyer_moore.py` — набір автоматизованих юніт-тестів, що перевіряють функцію на різних сценаріях: єдине входження, множинні входження, відсутність підрядка, порожні рядки, перекриття підрядків та робота з кириличними символами.

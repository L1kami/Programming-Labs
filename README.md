# Лабораторна робота №8

**Рівень 2, Варіант 2. Задача "Електрики" (Максимальна довжина дроту)**

## 📝 Опис завдання
Компанія проводить електромережу в село Вільшанка. Задіяні місцеві майстри встановили `N` електроопор, які знаходяться на однаковій відстані `w` одна від одної.
Точна висота кожної опори невідома — відомо лише, що висота `i`-ї опори знаходиться у межах `[1, heights[i]]`. Дріт приєднується до самої вершини опори.
Оскільки дріт замовляється з-за кордону і їхатиме довго, необхідно замовити його рівно стільки, скільки знадобиться для найгіршої ситуації. 

**Завдання:** Знайти таку послідовність висот опор, при якій дріт, що з'єднує їхні вершини, буде найдовшим.

## 📥 Вхідні дані
* **Перший рядок:** `w` — відстань між опорними стовпами.
* **Другий рядок:** `N` чисел, що описують максимальну можливу висоту для кожної опори (масив `heights`).

*Обмеження:*
* `w`, `heights[i]` — цілі числа у діапазоні 1 ... 100.
* `N < 50`.
* Фізичні обмеження на просідання дроту чи витрати на з'єднання ігноруються.

## 📤 Вихідні дані
Максимально можлива необхідна довжина дроту з точністю до 2 знаків після коми.

*Приклади:*

**Вхід 1:**
2
3 3 3
**Вихід 1:**
5.65

**Вхід 2:**
100
1 1 1 1
**Вихід 2:**
300

**Вхід 3:**
4
100 2 100 2 100
**Вихід 3:**
396.32

## 📂 Структура проєкту
* `wire_length.py` — скрипт, що містить реалізацію алгоритму динамічного програмування. Алгоритм базується на тому факті, що максимальна відстань завжди досягається, коли висота опори є або мінімальною (1), або максимальною (`heights[i]`).
* `test_wire_length.py` — набір автоматизованих юніт-тестів для перевірки роботи алгоритму на різних наборах даних, включаючи великі масиви та екстремальні чергування висот.

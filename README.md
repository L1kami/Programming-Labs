# Лабораторна робота №7

**Рівень 2, Варіант 2. Проєктування резервної мережі (Мінімальне кістякове дерево)**

## 📝 Опис завдання
Компанія ІоТ Телеком надає послуги інтернету та володіє мережею телекомунікаційних колодязів, між якими прокладені кабелі зв'язку. 
Для забезпечення роботи під час блекаутів компанія планує прокласти резервні лінії зв'язку. Оскільки оптоволоконний кабель є дорогим, необхідно з'єднати всі колодязі таким чином, щоб витратити мінімальну загальну довжину кабелю.

**Завдання:** Знайти мінімальну довжину оптоволоконного кабелю для з'єднання всіх вузлів мережі або визначити, що мережа є незв'язною.

## 📥 Вхідні дані
Програма зчитує дані з файлу `communication_wells.csv`. 
Кожен рядок файлу містить пару ідентифікаторів колодязів та відстань між ними у метрах, розділені комами.

*Приклад `communication_wells.csv`:*
K1, K2, 2000
K2, K3, 1500
K1, K3, 3000

## 📤 Вихідні дані
Функція повертає:
* **Ціле число** — мінімальна сумарна довжина кабелю.
* **`-1`** — якщо існують колодязі, які неможливо зв'язати з іншими (граф є незв'язним).

## 📂 Структура проєкту
* `telecom_network.py` — основний скрипт, що містить реалізацію структури даних Disjoint Set Union (DSU) та алгоритм Крускала для знаходження мінімального кістякового дерева (MST).
* `test_telecom_network.py` — набір автоматизованих юніт-тестів, які перевіряють роботу алгоритму на зв'язних, незв'язних та мінімальних графах за допомогою генерації тимчасових CSV-файлів.

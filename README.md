# Лабораторна робота №6

**РІвень 2, Варіант 2. Задача "Пиво" (Оптимізація закупівель для корпоративу)**

## 📝 Опис завдання
Аутсорс-компанія готується до корпоративу. HR-відділ провів опитування серед працівників щодо видів пива, які їм подобаються. 
Умови:
* Кожен працівник любить небагато видів пива.
* Кожному працівнику потрібно забезпечити принаймні один вид пива, який йому подобається, щоб уникнути образ.
* Закупити всі можливі види пива — занадто дорого.

**Завдання:** З'ясувати найменшу кількість різних видів пива, які потрібно привезти на свято, щоб задовольнити всіх працівників.

## 📥 Вхідні дані
Введення здійснюється через консоль:
1. Перший рядок: числа `N` (кількість працівників) та `B` (кількість доступних видів пива), розділені пробілом.
2. Другий рядок: рядок довжиною `N * B` символів (`Y` або `N`). Якщо літера на позиції `i * B + j` дорівнює `Y`, це означає, що працівнику `i` подобається пиво `j`.

*Обмеження:*
* Кожному працівнику подобається принаймні один вид пива.
* 0 < N <= 50
* 0 < B <= 50

*Приклад вводення:*
2 2
YNNY

## 📤 Вихідні дані
Програма виводить у консоль найменшу кількість видів пива, яку потрібно закупити на свято, а також перелік оптимальних комбінацій.

*Приклад виведення:*
Мінімальна кількість видів пива: 2
